# v0.6.3 — 可靠性与安全边界修复

本版集中修复错误反馈、异步状态一致性、缓存安全及键盘交互，不新增音频输出格式。

## 主要修复

- **歌词与 EQ**：歌词导入/在线匹配保留结构化错误原因；区分网络失败与未匹配。纯文本歌词静态展示，不按合成的四秒时间轴滚动或 seek；极端 LRC offset 在计算前钳制并使用饱和运算。EQ 频率、增益和 Q 值改为草稿输入，失焦或回车时整串提交，支持正常输入负值和小数。
- **设置一致性**：输出设备、驱动及系统集成设置按确认结果提示和回滚；连续操作使用代次与串行确认状态，旧响应不能覆盖新选择。设备丢失只刷新候选列表，不自动切到扬声器。鼠标穿透的常驻标志仅在窗口操作成功后提交。
- **播放与启动**：引擎命令 panic 后可重建，保留已确认的设备、驱动和音量；自动续播移出事件分发线程，与手动停止共享控制门闩。首帧渲染崩溃仍显示自救页面；增加单实例保护，重复启动唤起已有窗口。
- **缓存与外部程序**：整库清理、改缓存目录与在途下载/删除互斥；阻塞重封装线程保留来源租约。拒绝不安全缓存路径和伪造标记，保留无标记目录的原有文件；补齐配额、完成标记、孤儿临时文件回归。子进程运行、回收、stderr 读取均有上限，权限收窄失败不继续写会话文件。FFmpeg 查找拒绝相对路径与 PATH 空项。
- **下载凭据隔离**：CDN 下载不带登录 Cookie，地址白名单集中管理，拒绝 userinfo 和非标准端口；登录态仍用于官方 API。登录二维码改由纯 Rust 编码，移除前端 qrcode 依赖。
- **诊断与交互**：前端及歌词条警告/未捕获异常接入限长、限频、脱敏的轮转日志；错误通知停留更久，不被普通提示覆盖。菜单支持键盘和触控；弹窗补可访问名称、焦点返回与正确的嵌套关闭。歌单详情虚拟化，容器重挂不继承旧滚动位置；共享曲目索引减少重复查找。
- **工程化**：清除无调用方的旧 WASAPI 适配器和空壳 playlist crate；固定 Rust/cargo-audit 版本，增加前端 lint 与发布脚本测试，校验五类版本记录和发布说明；提供只打包不发布的手动演练。补充 MIT LICENSE 与第三方许可文本，随安装器分发。修复 undici 的兼容版本安全公告。

## 验证与边界

本地最终预检：前端 **382** 项、Rust **419** 项、发布脚本 **28** 项通过；ESLint 零警告、类型检查、Clippy、格式检查通过。NSIS x64 安装器已构建，文件版本 0.6.3。`npm audit` 无漏洞；不带 ignore 的 `cargo audit` 退出码 0，仍有未维护、unsound、yanked 警告。

OSV 补充核验覆盖 **678** 个 Rust 注册表依赖，未发现已知公告以外的新增阻断项；glib 公告及未维护依赖仍需跟踪。发布流水线会在 tag 推送后重新执行门禁并构建安装包。

- 未改变曲库清单格式（仍为 schema 2）。升级前仍建议备份应用数据目录。
- 缓存目录现在只接受本机磁盘绝对路径；有任务在途时清理/改目录会提示稍后重试。
- 原型冻结的主界面与 EQ 浏览器检查通过，但完整桌面链路尚未验收，因此 **freezePrototype 未开启**。
- 真实 DAC、蓝牙拔插、长时间播放与扫码登录仍需要实机验收。
- 无缝播放、bit-perfect/DoP/ASIO、ReplayGain、CUE、多语言等属于后续产品开发，本版不宣称已实现。
- 安装包没有新增 Authenticode 签名证书；SHA-256 校验值不能替代代码签名。
