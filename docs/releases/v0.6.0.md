# Seraph Audio Player v0.6.0

本版本带来 **歌词设置**：在线歌词源优先级、繁体中文转换、AMLL TTML 逐字歌词（含译文与音译）、歌词排除规则，并把任务栏歌词条的开关收拢到同一页。

## 新功能

- **歌词设置标签页**：设置弹窗新增「歌词设置」，任务栏歌词条的开关、位置滑块与鼠标穿透从「系统集成」迁入此页。
- **歌词源优先级**：自动 / 网易云音乐优先 / 酷狗音乐优先 / QQ 音乐优先。指定源的候选排在最前，其它源仍并发请求作兜底。
- **更喜欢繁体中文**：开启后，新获取或导入的歌词（原文、译文与逐字音节）转换为繁体中文；已保存的歌词不改写，关闭开关不逆转。转换由纯 Rust 词表（zhconv）完成，不依赖 C 库。
- **在线 TTML 歌词（Beta，默认开启）**：在线匹配时用网易云 / QQ 候选的歌曲 ID 到 AMLL TTML DB 查找逐字歌词，命中的候选排在最前并标记「AMLL TTML DB · 逐字」。TTML 的逐字时间轴、译文（`x-translation`）、音译（`x-roman`）与和声（`x-bg`）都会解析。
- **逐字高亮**：侧栏歌词稿、沉浸播放与任务栏歌词条的当前行按音节从左到右填色；进度由平滑时钟驱动，不受后端进度事件的百毫秒粒度影响。行级歌词仍沿用打字机动画。
- **译文与音译开关**：可分别显示或隐藏 TTML 译文 / 音译；双语 LRC 的相邻译文行照常显示。
- **AMLL TTML DB 地址**：两种模式。预设为社区镜像 `https://amlldb.bikonoo.com/ncm-lyrics/%s.ttml`；自定义模式接受任意公网 HTTPS 模板地址，占位符 `{dir}`（ncm-lyrics / qq-lyrics）、`{id}` 或 `%s`（歌曲 ID），不含占位符的地址按仓库根处理。弹窗实时显示展开后的示例请求，并附核心仓库、官方 API 文档、在线检索与 TTML 制作工具链接。
- **歌词排除配置**：按关键词（不区分大小写）或正则排除歌词行，原文、译文、音译任一命中即隐藏。匹配在 Rust 侧用 `regex` 完成（语法为 Rust regex，不支持环视与反向引用，编辑时逐键校验），后端回传歌词时打标记，主窗口与任务栏歌词条按同一份标记隐藏；规则改动即时广播生效。只影响显示，不修改已保存的歌词。
- **增强型 LRC 逐字歌词**：识别 LDDC / 网易云导出的行内 `<mm:ss.xxx>` 逐字时间标签，本地导入或目录匹配到这类 `.lrc` 即可获得逐字高亮，并随 `[offset:]` 一并校正。
- **本地歌词目录**：设置目录后，切歌时若曲库没有歌词，按「艺术家 - 曲名」在目录及其直接子目录内匹配 `.lrc` / `.qrc` / `.krc` / `.yrc` / `.ttml`（容忍版本后缀、全半角、多艺术家；跳过符号链接），命中即写入曲库。文件名括号里的网易云歌曲 ID（如 `王力宏 - 唯一 (65923804).lrc`）会记为该曲目的 AMLL 查找键，在线匹配时直接取逐字 TTML，不再依赖三源搜索命中。
- **QRC / KRC / YRC 逐字时间保留**：QQ、酷狗、网易云三源与本地导入的逐字格式不再压平为行级，音节起止随行输出，同样获得逐字高亮；酷狗译文行保持行级。
- **AMLL 官方索引 API**：DB 直取无命中时，按曲名 / 艺术家查询 `api.amll.dev` 索引，只有标题与艺术家高置信度匹配才取回 TTML 作为候选；模糊结果不自动绑定。索引固定走官方域并挂独立白名单，不受 DB 地址模式影响。
- **TTML 内存缓存**：DB 直取与索引查询共用进程级缓存，命中保留 30 分钟、未收录负缓存 5 分钟、网络失败不记录，上限 256 条。
- **AMLL 命中键回写**：应用 AMLL 候选时把其网易云 ID 写回曲目查找键，下次在线匹配直取。
- **本地 `.ttml` 导入与同名发现**：歌词稿「导入」接受 `.ttml`；导入按内容嗅探 TTML，不依赖扩展名；导入音频时同名 `.ttml` sidecar 优先于 `.lrc` 被发现并按 TTML 解析。
- **AMLL 地址「测试连接」**：地址弹窗新增测试按钮，对模板真发一次样例请求并区分：地址无效、不可达、目标未收录、服务返回错误、返回的是网页、不是有效 TTML XML、TTML 无可用行、连接正常（含解析行数）。
- **排除规则命中预览与预设**：规则弹窗列出当前曲目被隐藏的行（最多 30 行）；一键加入「制作信息」正则预设（默认不启用）。
- **隐藏句不并入上一句**：被规则隐藏的句子播放期间不再延长上一句高亮，点击定位时间不变；歌词全部被规则隐藏时，侧栏、沉浸播放与任务栏歌词条显示专用提示（侧栏附「打开歌词设置」直达歌词标签页），与「暂无歌词」区分。
- **歌词设置一键恢复默认**：设置页新增恢复按钮（二次确认），清空排除规则并同步后端。
- **沉浸页译文开关联动设置**：沉浸播放的译文按钮与「显示译文」设置读写同一状态。

## 安全边界

- 预设模式的地址固定为白名单域名，出站请求沿用逐跳重定向复验；官方索引 API 另挂 `api.amll.dev` 白名单，响应经 8 MB 上限的 JSON 读取。
- 自定义模式只接受 HTTPS 公网域名：拒绝 IP 直连、localhost、`.local` / `.internal` / `.lan` 等内网后缀与不带点的主机名；对自定义域名禁止跟随重定向。TTML 响应体读取上限 2 MB。
- 前端与后端各做一遍地址校验；持久化状态里的非法地址在启动时回退默认。应用候选时回写的查找键在后端按 `目录/ID` 字符集校验、去重并封顶 8 个。

## 兼容性

- 歌词数据模型新增可选字段（行结束时间、逐字音节、译文、音译、隐藏标记），旧曲库缓存无缝读取；行级歌词的存储格式不变。曲目新增可选的 AMLL 查找键字段。
- 歌词设置进入配置导出 / 导入范围。
- `fetch_online_lyrics` 与 `save_track_lyrics` 命令新增可选参数，`apply_online_lyrics` 新增可选 `lookupKeys`，旧调用方式仍可用；新增 `find_local_lyrics`、`set_lyrics_exclude_rules`、`validate_lyrics_exclude_rules`、`test_amll_ttml_db` 四个主窗口命令，任务栏歌词条命令白名单不变。在线候选新增 `lookupKeys` 字段。
- 仓库 `docs/` 目录只保留 `docs/releases/`，历史审查与规划报告不再入库。

## 修复

- 逐字歌词行曾因 `currentColor` 在文字透明后一并透明，导致当前行只剩译文、原文不可见；现使用具体颜色值并为不支持背景裁切的环境保留兜底。
- AMLL 地址非法时的提示文案仍提及已下线的 GitHub Raw / jsDelivr 镜像，现改为实际白名单。

## 验证

- 自动化回归：前端 **281 项**、Rust **328 项**（workspace，其中 `src-tauri` 库测试 212）；TypeScript 类型检查、Clippy（`-D warnings`）、Rust 格式检查通过。
- 已在本机 Windows 桌面构建安装包；AMLL 官方索引 API 与 DB 直取在本机用 curl 实测可达，播放器内联网命中依赖数据库收录情况，尚未做系统性实测。
