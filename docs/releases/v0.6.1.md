# Seraph Audio Player v0.6.1

本版本是一个 **逐字歌词专版**，围绕「大部分歌曲都能逐字」这个目标做了四件事：收尾增强型 LRC（ESLyric）并支持导出；修正在线三源取词管线，让酷狗、QQ 音乐、网易云真正返回逐字歌词与译文；把歌词数据模型重构为 `LyricDocument`（毫秒整数、结构化译文、来源身份），曲库清单升到版本 2；在此之上渲染和声、制作信息与对唱角色，支持同一时刻多句活动，并加入固定来源策略与两个显示选项。

## 新功能

### 增强型 LRC（ESLyric）收尾与导出

- **逐字 LRC（`[t]` 在文字后）**：识别 LDDC「逐字 LRC」写法 `[00:18.459]我[00:18.814]的[00:19.284]天[00:23.097]`，与增强型 `<t>` 写法共用同一套音节算法；首音节起点为行起点，行尾孤立标签为行结束，同受 `[offset:]` 校正。混合行以 `<t>` 优先，`[t]` 只作为文本内标签剥离。
- **首标签前的文字并入首音节**：`[00:01.00]Hello <00:01.50>world<00:02.00>` 里的 `Hello ` 不再从逐字高亮中消失。
- **末音节终点推导**：末音节没有结束标签时，整首歌排序后用下一句起点补齐音节终点与行结束时间，并标记为「推导值」；最后一句保持终点未知，行级歌词不合成结束时间。
- **LDDC 译文写法兼容**：识别「译文时间戳 = 下一句原文起点 − 1 ms」的导出格式，把译文并回它所属的原文句。
- **音节文本与整行一致**：逐字音节与整行文本走同一套清洗（HTML 实体、`<br>`、控制字符、全角空白）；QRC / KRC / YRC 音节同样受益。
- **导出歌词**：歌词稿右键菜单新增「导出歌词…」，可把当前曲目的歌词（含 TTML、QRC / KRC / YRC、增强 LRC 来源的逐字时间轴）写成增强型 LRC（ESLyric `<t>`）、逐字 LRC（`[t]`）或逐行 LRC；相邻音节共享时间标签，推导出来的终点不写标签，译文 / 音译按「显示译文 / 显示音译」开关各成一行，文件头写入曲名、艺术家、专辑与工具标记。导出的是曲库原始歌词，不受排除规则与显示选项影响。
- **间奏淡出**：带行结束时间的句子唱完 2 秒后、且距下一句至少 6 秒时，侧栏、沉浸播放与任务栏歌词条把当前句淡出；下一句临近或行级歌词不受影响。

### 在线逐字歌词覆盖率

此前「大部分歌拿不到逐字」的根因不在解析器，而在三源获取管线（2026-09-19 用真实文件与匿名接口实测）：

- **酷狗**：搜索接口只认「艺术家 - 曲名」形式的关键词（多艺术家用顿号），此前的拼法中 / 英 / 日歌曲一律 0 候选；现按接口拼法请求，零命中再退回纯曲名 + 时长，候选按接口评分再按时长差排序。
- **QQ 音乐**：网页端取词接口只有逐行；现改走客户端取词接口取加密 QRC，逐字原文、译文与音译一并解出（译文剔除 `//` 占位与注音行，音译按行拼音节），失败自动回退旧接口。QQ 的 3DES 是 S 盒、密钥压缩与字节序都有改动的**非标准变体**，标准实现只能解出乱码；现按实测自实现并附已知答案向量，顺带修好了此前从未真正解开过的本地加密 `.qrc` 文件。
- **网易云**：拿到逐字 yrc 时不再丢弃译文与音译，优先取与 yrc 对齐的译文轨；副轨按「起点差最小的一对一匹配」并入原文行，落单译文按自身时间保留。
- **酷狗 KRC 逐字罗马音**：`[language:]` 里的逐字罗马音表按非空原文行对回，作为音译显示。
- **候选排序与徽标**：三源候选按能力排序（逐字且带译文最前，其次逐字、译文、逐行），与本地时长明显不符的沉底但保留供手选；每张候选卡片标注「逐字 / 逐行」「译文」「音译」。
- **本地歌词文件的平台 ID**：LDDC 文件名括号里的数字可能是酷狗、QQ 或网易云任一平台的 ID，现同时按网易云与 QQ 两个目录查 AMLL TTML DB，命中后核对文件头里的曲名与艺术家，错平台的 ID 不再把无关歌曲的逐字歌词顶到候选最前。
- **歌词按可听位置定位**：引擎进度按送入设备缓冲的帧数计，逐字高亮此前领先可听音频约一个缓冲深度。进度事件现附带输出延迟（共享模式取回调时间戳，独占模式取设备缓冲填充量），侧栏、沉浸与任务栏三处的行定位、逐字锚点与间奏判定都据此回拨；进度条、跳转与记忆播放仍用引擎位置。

### 歌词数据模型重构

- 每首曲目的歌词是一份 `LyricDocument`：来源身份（内嵌 / 同名文件 / 歌词目录 / 手动导入 / 在线三源 / AMLL TTML，含平台 ID、AMLL 查找键与「固定」标记）、同步粒度（无 / 逐行 / 逐字）、文件 `[offset:]` 与行列表。
- 行与音节的时间一律**毫秒整数**；行结束时间可空并区分「来源给的」与「推导的」；译文与音译是结构化字段（TTML、KRC、网易云、QQ 的译文统一并入原文行），只有来源不明的双语 LRC 仍以相邻同起点两行表示并由显示层分组兜底；行带角色（主唱 / 和声 / 制作信息）与对唱标记。
- AMLL 查找键随歌词文档一起落盘：此前该字段从未写进曲库，重启即丢，导致下次在线匹配无法直取。
- 旧曲库（v0.6.0 及以前的秒制行数组）读入时自动迁移（秒→毫秒、零时长占位→终点未知、译文 / 音译字符串→结构，来源标记为旧版），首次保存写成新格式。

### 角色渲染、多活动区间、固定来源与显示选项

- **和声**：TTML 的 `x-bg` 不再并入主句文本，而是独立成行、挂在所在主句下显示，随主句一起按音节填色；容器自带的起止、译文与音译都归和声行。
- **制作信息**：作词 / 作曲 / 编曲这类行自动识别，单独成块、弱化显示，不参与打字机与逐字动画；网易云逐字歌词开头同起点的制作信息行不再被当成「译文」。
- **对唱**：同起点但演唱者不同的两句各自成句，不再按双语 LRC 合并。
- **多活动区间**：对唱重叠或和声延续时，同一时刻可以有多句处于活动状态并同时高亮；滚动、平滑时钟与间奏判定跟随「最早开始且仍在唱」的主句，短插句结束后自动回到仍在唱的长句；行级歌词保持原来的单句行为。任务栏歌词条只展示主句。
- **固定来源**：用户手动导入或明确应用的歌词标记为「固定」，重新导入音频（同名歌词文件、标签内嵌歌词）与本地歌词目录匹配都不会替换它；歌词稿右键菜单可「固定 / 取消固定歌词来源」，曲目信息弹窗显示歌词来源与固定状态。
- **显示制作信息**（默认开）与 **忽略歌词文件里的 offset**（默认关）：两个新设置与排除规则同一机制，由后端在回传歌词前投影（制作信息按隐藏标记、offset 还原到各行与音节），主窗口三处显示与任务栏歌词条天然一致，曲库里存的始终是解析原样；都进入配置导出 / 导入范围与「恢复歌词设置默认值」。

## 安全边界

- QQ 取词复用既有的歌词出站 client（`.qq.com` 白名单已覆盖新端点），**没有新增出站 client**；解密输入另有 hex 密文 2 MB、zlib 解压 8 MB 两道上限；自实现的 3DES 变体附真实密文块与样本文件的已知答案测试，`des` 依赖已移除。
- AMLL DB 直取命中后核对 TTML 文件头的曲名与艺术家，错平台 ID 取回的文件被拒绝而不是采信。
- 导出路径经既有 `validate_export_path` 校验（绝对路径、`.lrc` 扩展名、拒绝 `..`）；LRC 是行敏感、括号敏感的文本格式，导出时字段里的换行归一为空格、半角 `<>[]` 转为全角，回归闸为「导出 → 再解析」的往返测试。
- 新增的 `export_track_lyrics`、`set_lyrics_display_options`、`set_track_lyrics_pinned` 均为主窗口专用，任务栏歌词条命令白名单不变。

## 兼容性

- **曲库清单版本 1 → 2**：本版本读旧格式并自动迁移，首次保存即使内容不变也会整体重写为新格式；旧版本程序读不到迁移后的曲库变更，**回退前请先备份应用数据目录**。
- 歌词 IPC 全部改传整份 `LyricDocument`：`get_track_info` 返回的 `lyrics` 从行数组变为文档对象（`{schema, source, sync, offsetMs, lines}`），行字段改为 `startMs` / `endMs` / `translations[]` / `roman`；曲目上的 `lyricsLookupKeys` 移除，查找键位于 `lyrics.source.lookupKeys`。在线候选的 `lyrics` 同形；来源标签不再带「· 逐字」后缀，改由徽标表达。
- 播放进度事件新增 `output_latency` 字段（秒），旧载荷按 0 处理。
- 新增 `showLyricsCredits`、`ignoreLyricsFileOffset` 两个设置字段并进入配置导出。
- 此前解析出的逐字歌词在重新导入或在线匹配后才会获得本版本的终点推导、文本清洗与角色识别；已存歌词的迁移只做单位与结构换算，不重新解析。

## 修复

- 酷狗搜索关键词拼法导致几乎所有歌曲 0 候选。
- 网易云拿到逐字 yrc 后译文与音译被整体丢弃。
- 本地加密 `.qrc` 文件此前解不开却静默按普通文本回退。
- AMLL 查找键未落盘，重启后丢失。
- 逐字高亮领先可听音频约一个设备缓冲深度。
- 网易云逐字歌词开头的制作信息行被当作首句译文显示。
