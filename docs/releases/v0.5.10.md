# Seraph Audio Player v0.5.10

本版本修复切歌后的歌词滞后，以及随机播放时「下一首」预览与实际播放曲目不一致的问题。

## 修复内容

- 切歌或替换歌词后立即重新定位，清除上一首的滚动位置和手动浏览暂停状态。新歌有前奏时也会回到歌词开头。
- 过滤上一首迟到的播放进度，避免新歌的歌词跳回开头；起播事件也能同步当前曲目。
- 任务栏歌词条在新曲目加载期间停止展示旧歌词；连续切歌时丢弃旧请求，迟到的启动快照不会覆盖最新的曲目、进度或暂停状态。
- 随机播放由后端提前确定并保留下一首，预览卡片、下一首按钮、系统媒体键和自动续播共用这一结果。
- 重复同步队列或更新标题、封面时保留下一首选择；单曲循环的行为保持不变。

## 验证

- 新增 19 项前端回归测试，覆盖歌词滚动、任务栏歌词、切歌事件和下一首预览同步。
- 新增 8 项 Rust 队列测试，包含连续 64 次随机切歌与预览的一致性检查。
- 前端完整测试、Rust 工作区测试、TypeScript 类型检查和 Clippy 静态检查通过。

- 也可选择英文或简体中文 MSI 安装包。
