# Seraph Audio Player v0.6.6

第三轮审查清单修复与声场散点加密：曲库存储与导入防线、路径与外部解码保护、设备枚举与本地歌词索引优化、在线封面匹配收紧、声场可视化散点加密，以及依赖安全升级。

## 声场可视化

- **沉浸页与分析页声场散点加密**：沉浸页每帧固定取 1440 个真实采样点、余晖由 6 帧改为 10 帧（`0.7 × 0.8^k`）、点径 1.4～2.6 px，画布像素比取设备像素比的整数倍且至少为 2（150% 系统缩放下散点不再插值发虚）；分析页每帧固定取 960 个真实采样点，点径 2.2～3.4 px。移除按画布尺寸分档的旧逻辑。
- 新增 `scripts/field-preview.html`，可直接导入实际绘制函数渲染合成信号预览调参效果。

## 曲库存储与导入

- **第三代按天滚动快照（`library-snapshot.daily.json`）**：最多每 24 小时更新一次；当前清单损坏且上一版不可用时，按「上一版 → 每日快照」顺序回退恢复，清理旧代次时保留三份清单引用的文件。
- **`.corrupt` 备份去重与失败记忆**：同一份坏内容不重复备份，每目录最多保留 8 份本模块生成的 `.corrupt` 现场；冷读失败按存储文件指纹在进程内记忆，文件未变不再重读数十 MB 快照。
- **固定落盘哈希算法**：本地曲目 ID、封面文件名与旧设备 ID 改用自带 SipHash-1-3 实现，输出与此前逐位相同，已有曲库无需迁移，升级工具链不再变更曲目 ID。
- **导入筛查与同名歌词提速**：已知非音频扩展名直接跳过嗅探；MPEG/ADTS 帧头判定排除保留值，UTF-16 LE（`FF FE`）抓轨日志不再误判为 MP3；一次导入内每个目录仅枚举一次同名歌词。
- 曲目列表改用共享虚拟滚动（`useVirtualRows`），改搜索词或排序后回到顶部并清除旧滚动位置。

## 路径安全与导出

- **M3U8 与文件定位路径防线**：导入 M3U8 先按路径写法分类再探测，网络共享路径仅探测清单所在主机与曲库已有主机，其余网络路径与设备路径跳过并提示主机名和补救方式；「在资源管理器中显示」对网络路径只接受曲库已有曲目，设备路径一律拒绝；系统工具路径改走 Win32 API 定位。
- **原子写与导出校准**：配置、EQ 预设、歌词与歌单导出统一走「同目录临时文件 + 落盘同步 + 改名」原子写；LRC 导出行数按序列化实际行数统计；应用在线歌词时对回传文档再过一次上限裁剪。

## 解码、设备与封面

- **ffmpeg 回退路径读取与回收有界**：stdout 改由独立读线程经有界通道转交，连续 30 秒无数据即判定超时并终止进程；kill 回收、读线程收尾与 ffprobe 超时路径全部限时 2 秒。ffprobe 未知位深记为 0 且不覆盖有效位深（独占模式下不再把未知位深源误量化到 16 bit）。
- **设备枚举合并**：切换输出设备与起播时的设备解析与端点 ID 获取合并为单轮枚举（`resolve_output_device`）。
- **在线封面匹配收紧**：仅采用曲名相同（简繁、全半角、大小写、标点不敏感；去括号后缀后相同的排在后面）且曲目有艺术家时须有一位相符的结果，无艺术家时要求曲名完全相同；QQ 专辑 ID 拼址前校验为字母数字并最多试 3 张，封面 client 进程内复用。

## 歌词、设置与交互

- 歌词排除规则与两个显示选项（「显示制作信息」「忽略歌词文件 offset」）改为串行队列提交，后端拒绝时回滚到已确认值并按错误级别提示；EQ 下发失败按原因去重提示；FFmpeg 下载、登录二维码与 B 站状态刷新失败统一带上原因。
- 手动导入歌词改以 base64 文本过 IPC；本地歌词目录文件名索引按目录修改时间缓存（2 秒稳定余量与 5 分钟上限兜底）。

## 依赖升级

- 按两道安全审计精确升级 Rust 依赖：`cookie` 0.18.1 → 0.18.3、`url` 2.5.8 → 2.5.9（连带 `form_urlencoded` 1.2.2 → 1.2.3），不加任何 ignore。

## 未包含在本版

- 第三轮清单中的 `DEV-02`（共享模式同名设备按端点 ID 打开，需两台同名设备实测）与 `LIB-01` 不依赖路径的内容指纹部分，以及前几轮其余未处理项，将在后续版本跟进。

## 回归覆盖

前端 580 项、Rust 557 项、发布脚本 28 项自动化测试通过（合计 1165 项；Rust 另有 2 项忽略测试不计入）。

## 需要实机留意

本版改动只通过了自动化测试与离屏缩放对比，**没有在真实音频硬件与真实网络环境下逐一实机验证**，升级后如发现异常请反馈：沉浸/分析页声场 10 帧余晖拖尾感与低配流畅度、含非音频文件与网络路径 M3U8 的导入、ffmpeg 回退解码超时与 24 bit 独占输出、设备切换、在线封面匹配结果，以及曲目列表滚动行为。
