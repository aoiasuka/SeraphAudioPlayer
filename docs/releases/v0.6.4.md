# Seraph Audio Player v0.6.4

音质、稳定性与体验修复专版。本版处理了四轮只读审查清单中的两份：第四轮清单的全部 13 个编号项，以及第一轮清单中音频引擎、后端与前端的大部分条目。

## 音频引擎与音质

- **切换输出设备失败不再误报「已停止」**：新设备打不开、引擎已回滚到旧设备继续出声时，界面此前会显示暂停、曲终也不再自动切下一首。现在只有会话确实停止才上报停止。
- **切换输出驱动失败会回滚**：此前引擎停在起不来的新驱动上，之后每次播放都失败。
- **独占模式不可用时自动改用共享模式**：设备不支持当前曲目的声道数或采样率、或被其它程序占用时，这一首自动退回共享模式并提示一次；所选驱动不变，下一首照旧先试独占。
- **重采样器重写**：改用 Kaiser 窗，滤波核随降采样比加宽。192 kHz → 48 kHz 时对 24 kHz 以上内容的抑制从十几 dB 提高到 70 dB 以上，通带到 19 kHz 平直（±0.1 dB 内）。权重每个输出帧只算一次。
- **按需 dither**：16 位源在音量 100%、未开均衡器、未重采样时原样输出，不再无条件叠加噪声；24 位输出同样只对被改动过的信号加 dither。
- **解码断流后恢复出声走淡入**，不再从静音直接跳到满幅。
- **分析页的响度、峰值与频谱不再随音量滑块变化**，反映的是曲目本身。
- **Crossfeed 不再让居中声像变暗**：直达声改为与对侧低通互补的高架，左右相同的内容全频段保持不变。
- 独占渲染线程登记为系统「Pro Audio」任务并命名；渲染线程的等待改为有界，卡住的驱动调用不再拖死引擎。

## 均衡器

- **GraphicEQ 预设导入修复**：此前超过 60 个点时只保留前 60 个（全在低频），中高频完全没有被校正。现在在整个频率范围内重采样为 31 段，并用最小二乘拟合各段增益，使实际响应贴合原曲线。
- 频段数量上限统一为 64（手动添加、预设导入、后端兜底同一个值）；导出预设时频率保留一位小数。

## 歌词

- **繁体转换按整行上下文进行**：一字一音节的逐字歌词此前逐音节转换，「头发」唱到时显示「頭發」、唱完显示「頭髮」。现在逐字行与整行用字一致。
- 逐字高亮的平滑时钟外推封顶 500 ms，进度事件中断时不再与声音脱节。
- 侧栏与沉浸页的歌词不再随每次进度事件整篇重渲染。
- 读取 DSF / DFF 文件内嵌的歌词。

## 曲库与流媒体

- 专辑名恰好是「Bilibili」的本地曲目不再被当成流媒体，可以正常删除。
- 流媒体页的杜比 / FLAC / 混流三个选项会被记住；登录二维码改为标准弹窗（可用 Esc 关闭）；已登录状态 5 分钟内不重复联网查询。
- 曲库写入少做一次全库深拷贝；批量删除不再对全库每个路径做文件系统调用。
- 构造的 DSF / DFF 文件（块大小全为 0）不再让打开文件的线程长时间空转。

## 界面与可访问性

- **进度条可用键盘操作**：方向键步进 5 秒，PageUp / PageDown 步进 30 秒，Home / End 跳首尾。
- **标题栏新增「最近通知」**，保留本次运行最近 50 条；错误提示可以手动关闭。
- 右键菜单关闭后焦点回到原来的元素。
- 弱化文字的对比度提高；设置页标签与侧栏导航补全读屏语义；系统开启「减弱动态效果」时打字机与旋转动画关闭。
- 「恢复歌词设置默认值」改用应用内确认弹窗。
- 启动画面改为纯 CSS 动画，主包不再包含动画库。

## 错误提示

- 播放、哔哩哔哩与系统命令统一返回带错误码的结构化错误，前端按错误码给出中文提示，不再靠消息里的子串猜测类型。
- 播放失败不再连续弹出两条内容相同的提示。

## 依赖与安全

- 发布当天两道审计均不带 ignore 通过。npm 侧修复 undici、source-map-js 等公告；Rust 侧升级 quinn-proto、quinn-udp、rustls、rustls-webpki、webpki-root-certs、tokio、rustix，并把 zip 从 2.x 升到 9.x。
- `cargo audit` 仍有 17 条「未维护 / unsound」类警告（均为既有传递依赖，无可用修复版），未做忽略处理。
