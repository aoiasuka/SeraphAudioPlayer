# Seraph Audio Player v0.5.11

本次修复深度筛查发现的 **12 类 BUG**，改善启动静音、配置恢复、播放状态一致性、随机历史回退及声学分析。

## 修复内容

- **启动与系统媒体续播**：引擎在播放配置到达前保持静音，启动立即同步已保存的音量和静音状态；暂停 A 后选中 B，系统媒体播放会加载 B，同曲恢复则保留暂停位置。
- **删除与重缓存竞态**：重缓存按稳定曲目 ID 更新；删除入口立即取消旧播放意图，后端在写盘前确认目标仍存在且来源匹配，避免覆盖其他曲目或使已删除记录重新入库。
- **设备与驱动切换**：丢弃旧设备枚举响应；切驱动期间发生新选曲或定位时，旧续播不能覆盖新操作，实际起播读取最新位置。
- **任务栏设置与配置校验**：5 项任务栏设置单独修改也能持久化；同版本配置导入同样清洗非法页面、音量及分析面板数据。
- **播放错误一致性**：可恢复的定位失败回滚进度、给出提示并保留播放态；下一首文件打开失败时，前后端均保留该曲目的选择并停止，下一次可继续推进。
- **随机播放历史**：历史游标与随机去重分离，支持连续后退、前进、删除历史曲目和手动改选分支。
- **频谱与多声道分析**：FFT 频率坐标按实际采样率换算，与前端的 20 Hz～20 kHz 坐标一致；多声道采样缓冲溢出后保持完整帧，半帧延后读取，格式变化时清空旧样本。

## 验证与发布

- 新增 **31 项回归测试**：前端 18 项、Rust 13 项。
- 完整自动化测试：前端 **187 项**、Rust **268 项**，合计 **455 项**。
- 类型检查、Clippy 和 Rust 格式检查已通过；发布工作流执行前后端测试及两道依赖审计。
- Windows x64 提供 NSIS EXE 安装器，以及 `en-US` / `zh-CN` MSI。
- 发布说明由工作流直接读取本文件，随同版本代码与安装包发布。

自动化验证使用模拟 IPC、无声卡播放会话及合成音频样本；真实 DAC、蓝牙设备切换和系统媒体键尚未完成桌面实测。
